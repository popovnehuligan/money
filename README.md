# Money

A personal finance tracker for one Tatra banka account. It runs entirely on free tiers: Cloudflare Workers + D1, Telegram, and Google Apps Script.

```
Tatra banka b-mail (e-mail) ──► your Gmail ──► Apps Script, every minute (free)
                                                 │  POST /ingest
                                                 ▼
                              Cloudflare Worker + D1 database (free)
                               ├─ reads the b-mail, skips duplicates, reuses your past choices
                               ├─ Telegram message per payment, with buttons to sort it
                               ├─ every morning: "safe to spend today"; on the 1st: month wrap-up
                               └─ dashboard (Telegram Mini App, can be added to the home screen)
```

## What counts as what

| Kind | Meaning | Counted as |
|---|---|---|
| 💸 Spend | normal spending (Google Pay, card, cash) | expense, by category |
| 💰 Income | salary, gifts | income |
| 🔁 Podmoga | job money you only pass on (500 € in, 400 € out) | only the **net** (+100 € income); a loss counts as spending |
| 🏦 Savings | moves to/from your savings account | "saved", never spending |
| 🚫 Ignore | moves between your own accounts | nothing |

You choose the kind or category once with a button. Payments to the same shop, IBAN or person get the same choice automatically after that.

**Missing movements.** b-mail doesn't report everything; Tatra banka says it skips transactions generated by its core system, such as fees and interest. When a b-mail includes your balance and the balance moved more than the payment explains, the bot adds an **"Unexplained balance change"** entry and asks what it was. If you mark a −100 € gap as 🏦 Savings once, the next −100 € gap is recognised as savings automatically. Turn this off with `/gaps off`.

**Daily allowance.** `/budget 600` sets a monthly spending budget. Each morning you get *(budget − spent so far) ÷ days left*. Underspending makes the following days bigger. The 👍/👎 buttons let you mark purchases you regret; the monthly wrap-up shows how much that was.

## ⚠️ Before relying on it

The b-mail parser (`src/parse.ts`) was written **without a real b-mail to look at**, so it guesses the format. A b-mail it can't read isn't lost: it is stored and shown in Telegram as "couldn't read". To fix it, take 3–5 real b-mails (a card payment, an incoming transfer and an outgoing transfer), redact the names and IBANs, and add them to `test/parse.test.ts`. Then adjust the parser until they pass.

This repository is **public**. It contains no personal data: transactions live only in your Cloudflare D1 database, and secrets live in GitHub/Cloudflare secrets. Never commit real b-mails without redacting them.

## Setup (about 30 minutes, all in a browser)

1. **Tatra banka**: in the app go to Nastavenia → b-mail. Turn on **e-mail** notifications to your Gmail for the current account: card payments, incoming payments and outgoing payments, with no minimum amount. As far as I could find, e-mail and push are free and SMS costs extra.
2. **Telegram**: talk to [@BotFather](https://t.me/BotFather), send `/newbot`, and copy the token.
3. **Cloudflare** (free account):
   - Storage & Databases → D1 → *Create* a database named `money`. Copy its ID.
   - My Profile → API Tokens → *Create token* using the "Edit Cloudflare Workers" template, then add the permission *Account → D1 → Edit*.
   - Copy your Account ID (shown on the Workers overview page).
4. **GitHub** → this repo → Settings → Secrets and variables → Actions:
   - Variable `D1_DATABASE_ID`: the D1 ID.
   - Secrets:
     - `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.
     - `TELEGRAM_TOKEN`.
     - `TELEGRAM_SECRET` and `INGEST_SECRET`: two different random strings of 32+ letters and digits, from any password generator.
     - Optionally `OWN_IBANS`: your own IBANs, comma-separated, so they're never taken as the other party.
   - Actions → *Deploy* → *Run workflow*. The log shows your URL, e.g. `https://money.<you>.workers.dev`.
5. **Connect the bot**: open `https://money.<you>.workers.dev/setup?key=<INGEST_SECRET>`. Then message your bot; it replies with your chat id. Save it as the `CHAT_ID` secret, run *Deploy* again, and open the `/setup` link once more. The 📊 menu button now opens the dashboard; inside it, *Add to home screen* gives you an app icon.
6. **Gmail forwarder**: go to [script.google.com](https://script.google.com) → *New project* and paste `apps-script/Code.gs`.
   - Project settings → Script properties: add `WORKER_URL` (`https://money.<you>.workers.dev/ingest`) and `INGEST_SECRET`.
   - Open one real b-mail and check that `QUERY` at the top matches its sender.
   - Run `install` and allow the Gmail access it asks for.
   - Optionally run `backfill` to import the last 180 days silently.

## Daily use

- Pay with Google Pay as usual. The Telegram message arrives about a minute later; tap a category, plus 👍/👎 if you like.
- For cash, type `4.50 kava` into the bot. Use `+20 gift` for money you received.
- Commands: `/today`, `/month`, `/month last`, `/budget 600`, `/gaps off`.

## Free-tier limits

- Workers: 100k requests/day.
- D1: 5 GB of storage.
- Apps Script: 20k URL fetches/day.

One person's payments use a tiny fraction of each.
